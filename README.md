# 100 Projects of Verilog

Welcome to my 100 Projects of Verilog Challenge!

I am learning Verilog HDL through 100 hands-on projects using Icarus Verilog and GTKWave.

Goals

- Learn Verilog from basics to advanced.
- Understand digital design concepts.
- Build practical Verilog projects.
- Improve RTL coding and simulation skills.

Tools Used

- Verilog HDL
- Icarus Verilog
- GTKWave
- VS Code
- Git and GitHub



Let's learn, build and grow! 🚀
